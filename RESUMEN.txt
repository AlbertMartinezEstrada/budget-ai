# RESUMEN EJECUTIVO - Budget AI

## ✅ TU PROYECTO YA GUARDA EN POSTGRESQL

El proyecto budget-ai está completamente configurado para almacenar datos en PostgreSQL.

## 🔄 FLUJO COMPLETO

```
CSV → Frontend (puerto 3000) → API FastAPI (puerto 8000)
                                      ↓
                               bank_reader.py (limpia datos)
                                      ↓
                               ai_engine.py (Gemini clasifica)
                                      ↓
                               PostgreSQL (guarda en tabla despeses)
                                      ↓
                               GET /gastos → Frontend muestra datos
```

## 📁 DOS PROYECTOS EN EL REPO

1. **budget-ai** (CON BD PostgreSQL)
   - Backend: FastAPI + PostgreSQL
   - Frontend: HTML simple
   - Puerto: 3000

2. **assistent-financer-personal** (SIN BD)
   - Solo React + Vite + Gemini directo
   - Puerto: 3000
   - NO conectado con budget-ai
