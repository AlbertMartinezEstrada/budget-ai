# Frontend - Node.js/Express

## Project Type
Node.js web client application using Express

## Tech Stack
- **Runtime**: Node.js
- **Framework**: Express.js
- **Package Manager**: npm
- **Language**: JavaScript (CommonJS)

## SDK Required
- Node.js SDK (configure in IntelliJ IDEA)

## Key Files
- `index.js` - Entry point
- `public/js/app.js` - Main application logic
- `public/js/api.js` - API client

## Run
```bash
npm start
```

## Dependencies
- axios: HTTP client
- express: Web framework
